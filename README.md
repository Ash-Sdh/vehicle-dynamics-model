# vehicle-dynamics-model
Vehicle dynamics models for MLTS: 2-wheel and 4-wheel model development.

This repository is for developing vehicle dynamics models for MLTS.

## Current focus

- 2-wheel / bicycle model
- Slip angle calculation
- Linear tyre model
- Lateral force calculation
- Yaw rate and lateral velocity simulation

## Future work

- Nonlinear tyre saturation
- 4-wheel model
- Validation with measurement data
